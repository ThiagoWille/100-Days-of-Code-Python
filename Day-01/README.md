🎸 Day 1: Band Name Generator (Gerador de Nomes de Banda)
Um programa simples, mas essencial, para praticar a interação inicial entre o usuário e o software via console.

O que aprendi: Manipulação de strings, uso da função input() para capturar dados em tempo real e a função print() para exibir resultados processados.

Conceitos Técnicos: Pratiquei a concatenação de strings e o uso de caracteres de escape como o \n para criar uma interface de usuário mais limpa no terminal.
