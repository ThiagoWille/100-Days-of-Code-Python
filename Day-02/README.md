🧮 Day 2: Tip Calculator (Calculadora de Gorjetas)
Um projeto focado na manipulação de tipos de dados e na aplicação de lógica matemática para resolver problemas financeiros do cotidiano.

- O que aprendi: Aprofundamento nos tipos de dados primitivos, conversão de tipos (Type Casting) e formatação de saída de dados.

- Conceitos Técnicos:

  - Tipos Primitivos: Diferenciação prática entre Strings, Integers, Floats e Booleans.  

  - Operadores Matemáticos: Uso de precedência matemática e operadores de atribuição (+=, -=, etc.).  

  - Manipulação de Números: Arredondamento preciso com a função round() e o uso de f-strings para exibição dinâmica de variáveis sem a          necessidade de conversão manual de string
