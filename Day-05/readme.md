# 🔁 Day 5: Python Loops e Lógica de Iteração

Este repositório documenta o quinto dia de estudos, focado no domínio do loop `for`, manipulação de sequências com `range()` e o desenvolvimento de algoritmos de busca e geração de dados.

## 🛠️ Conceitos Explorados
* **For Loops**: Iteração sobre listas para processamento individual de elementos.
* **Funções de Acúmulo**: Implementação manual de funções integradas como `sum()` e `max()` para entender a persistência de estado em variáveis externas.
* **Função Range**: Geração de sequências numéricas customizadas, definindo início, fim e intervalo (step).
* **Controle de Fluxo Complexo**: Resolução do clássico desafio **FizzBuzz**, utilizando precedência lógica e operadores de módulo (`%`).

---

## 🔐 Projeto Final: PyPassword Generator
Um gerador de senhas robusto que permite ao usuário definir a complexidade através da quantidade de letras, números e símbolos.

**Destaques Técnicos:**
* **Versão "Hard"**: Implementação de um algoritmo de embaralhamento que remove qualquer padrão sequencial da senha.
* **Data Type Handling**: Conversão dinâmica entre Strings e Listas para possibilitar o uso do método `random.shuffle()`.
* **Segurança Aleatória**: Uso do módulo `random` para garantir a imprevisibilidade de cada caractere gerado.

---

## 📂 Exercícios de Lógica
1. **Highest Score**: Algoritmo de busca para encontrar o maior valor em uma lista sem utilizar a função `max()`.
2. **Adding Even Numbers**: Uso do `range()` com "step" para realizar cálculos matemáticos em intervalos específicos.
3. **FizzBuzz**: Implementação da lógica de divisibilidade múltipla para filtragem de sequências numéricas.
