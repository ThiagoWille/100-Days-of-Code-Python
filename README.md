# 🐍 100 Days of Code - Python

Este repositório contém a minha jornada de aprendizado em Python, seguindo o curso da Dra. Angela Yu. Como estudante de **Análise e Desenvolvimento de Sistemas** e **Full Stack Python**, meu objetivo aqui é documentar a evolução da minha lógica de programação e a resolução de problemas reais.

## 🚀 Projetos Destaque

### 🏝️ Day 3: Treasure Island (Ilha do Tesouro)
Um jogo de aventura em texto focado em estruturas condicionais complexas (`if/elif/else`).
- **O que aprendi:** Tratamento de strings com `.lower()` e `.strip()`, lógica de decisão aninhada e validação de entradas do usuário.
- **Diferencial:** Implementação de artes ASCII personalizadas para melhorar a experiência do usuário no terminal.
